# 🎮 Word Guessing Game

A simple and fun Word Guessing Game built using Python and Streamlit.

## 🌐 Live Demo

**[Play Word Guessing Game](https://rasagnika-gr-word-guessing-game-app-dpvjjn.streamlit.app/)**

## About

This is a simple tutorial project I created while practising Python. I wanted to take my Python learning a step further by turning the game into a webpage so that anyone can play it online.

## Features

- Random word selection
- 10 attempts to guess the word
- Interactive letter guessing
- Win and lose conditions
- New Game option

## Technologies Used

- Python
- Streamlit

## Run Locally
pip install -r requirements.txt
streamlit run app.py
